# ERC-3643 Attack Vectors in Depth

A security reference for the [ERC-3643 / T-REX](https://github.com/TokenySolutions/ERC-3643) security token suite.

This repository tracks the most common and high-impact ways ERC-3643 deployments can fail in production, from trusted-issuer key management to launch misconfiguration.
